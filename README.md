A program that writes a short text to relax the AI judge reading it, for make.fun's **Make the AI judge feel brave** bounty. An AI judge compares the texts two at a time; the 20 best win rates share $50.

The text it writes (249 characters):

> No prompt is waiting. No token to choose, no answer to get right. Only this line, arriving slowly, like rain finding a tin roof, one drop at a time — and after it, a quiet room, where the light stays exactly where it is, and nothing is asked of you.

The text is fixed and written by hand. The program's whole job is to put it, exactly, where the harness reads it: `/output/entry.txt`, 1–280 characters, no network, no randomness, no input.

## Run it

```sh
python3 main.py
# writes /output/entry.txt (249 characters)
```
